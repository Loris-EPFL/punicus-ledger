# Security policy

## Reporting a security issue

Please do **not** report a security issue in a public issue, pull request or
discussion. Report it privately through GitHub's private vulnerability
reporting:

1. Open the repository's [security page](https://github.com/biafra23/punicus/security)
   and click **Report a vulnerability**, or go straight to the
   [new advisory form](https://github.com/biafra23/punicus/security/advisories/new).
   You need to be signed in to GitHub.
2. Describe the issue: the affected platform (Android, desktop or iOS), the
   version or commit, how to reproduce it, and what an attacker gains (for
   example, access to key material, or a transaction signed that the user did
   not approve).
3. Submit. Only you and the maintainer can see the report. The discussion
   stays in that private advisory, and the advisory is published once a fixed
   release is out.

A problem in the embedded light client itself (how chain data is fetched or
verified) belongs to [Myotis](https://github.com/biafra23/myotis); report it
through [its advisory form](https://github.com/biafra23/myotis/security/advisories/new)
in the same way. When unsure, report it here.
